## Observation-only additions (M7 only)

Both existing deterministic TRAIN-fit passes keep their original CE, argmax,
ID/options/target position, source/group/family and aggregate mean CE. Each row
additionally stores full ordered `allowed_logits` and
`conditional_probabilities`, `allowed_answer_ids` (token IDs), `target_id`,
`option_count`, probability/logit top positions, top probability and raw logit,
probability top option IDs, exact top-tie counts, and top-two probability margin.
Vectors align with `option_ids`; positions are zero-based. Ties are exact FP32
value equality, independently for logits and probabilities; rounding can make
these top sets differ. Existing argmax remains first raw-logit maximum.
Probabilities are conditional softmax over allowed answers only, checked finite,
in [0,1], normalized within 1e-6. These are not calibration claims.

Everything is derived inside the existing `no_grad` fit from the same logits;
there are no extra forwards, objectives or changes to mean CE. Full vectors
allow owners to compute entropy/Brier/uniform comparisons without adding metric
selection here. `gradient-norms.jsonl` flushes each already-computed preclip norm
once, before the corresponding update, with 1-based update/presentation counts;
a complete run has 375 values. Partial/failed streams remain evidence, not a
completed trajectory. No second norm calculation or weight scan is added.

## Runtime handoff

The unchanged flat `jeff.qwen-trained-checkpoint.v1` manifest is written only for
complete training; fields/status/kind/source_run_receipt and file inventory
semantics are unchanged. HF safe weights and the original four tokenizer bytes
are saved as before. M7 `run_id` is metadata-only
`<parent-run-root-name>/<training-directory-name>` (normally
`m7-qwen-low-lr-20261111-01/training`), with `-checkpoint` appended for
`checkpoint_id`; M6 retains its historical directory-name IDs. This qualified
producer ID is not a filesystem path used by the Runtime validator. Outputs
are immutable and failures retain receipts/events without a complete manifest.
Only checkpoint/ and checkpoint-manifest.json go to Runtime; TRAIN-labelled
schedules/fit rows stay with Model. P5 owns the fresh final pass, not this module.
