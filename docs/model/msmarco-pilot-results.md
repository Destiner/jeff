# M3: retained-pretrained-head MS MARCO cross-encoder

## Implementation

M3 adds an explicit `--architecture retained_cross_encoder` path using `cross-encoder/ms-marco-MiniLM-L6-v2@233902d25c440f23af6f7d6e94d2946bac0bee0a` (Apache-2.0). It retains the native BERT pooled-CLS, dropout and pretrained one-logit classifier. It is a retrieval-relevance model, not inherently a correct-answer classifier.

Input text pairs and all shared decision fields remain unchanged. The model returns one **raw scalar logit per candidate**, padded with negative infinity for variable choice counts. Training computes external cross-entropy across the candidate dimension. No `labels` are passed to the Hugging Face classifier (which otherwise could choose a one-label regression loss), and no sigmoid is applied before choice softmax.

The old `mean_pool_scalar` path remains the default. Its random-head initialization and v1 checkpoint format continue to work. New checkpoints have a distinct architecture tag and contain the complete sequence classifier—including its head—in `encoder/`, with local tokenizer files. The inference dispatcher supports both formats with no network fallback.

## Controlled pilot

Frozen `data-pilot-v1`, same 300 train / 60 validation, seed 42, 256-token budget, three epochs, batch four, 225 updates / 900 presentations, backbone/head learning rates 2e-5 / 5e-4, MPS. No data, dependencies, final evaluation or paid services changed. The comparison changes the pretrained source and native scoring architecture together; it does **not** isolate the effect of the head alone.

Actual implementation revision: `e37b0f3e7f2e3162abca87a76883eb81300603e0`, clean. The matching starting model is a **retained pretrained ranking head**, not a random-head baseline.

Retention evidence is stronger than a configuration claim: all 105 saved baseline parameter tensors exactly equal upstream safetensors, including classifier weight/bias and BERT pooler weight/bias. Upstream additionally stores `bert.embeddings.position_ids`, a non-persistent buffer regenerated by Transformers; it is not a lost learned parameter. Head hashes were also checked unchanged immediately before baseline save. Training then changed 105 parameter tensors; representative embedding/head-weight L2 deltas: 0.245790 / 0.158269.

## Same-input validation result

All six models were scored on identical 60-row references / **12 source groups**, with full coverage and no prediction failures.

| Run | Mixed reference-label agreement | Mean log loss |
| --- | ---: | ---: |
| Uniform, first-option ties | 17/60 (28.3%) | 1.378765 |
| Lexical | 29/60 (48.3%) | 1.323710 |
| M2 all-MiniLM random head, 256 | 20/60 (33.3%) | 1.378267 |
| M2 all-MiniLM trained, 256 | 35/60 (58.3%) | 0.855288 |
| M3 MS MARCO retained pretrained head | 30/60 (50.0%) | 1.026878 |
| M3 MS MARCO trained | **40/60 (66.7%)** | **0.793701** |

| Family / provenance | Rows / groups | M3 starting → trained | Log loss, starting → trained | M2 trained |
| --- | ---: | ---: | ---: | ---: |
| Intent / teacher agreement | 20 / 5 | 18/20 → 19/20 | 0.381560 → 0.211817 | 20/20 |
| Sentiment / teacher agreement | 20 / 5 | 7/20 → 14/20 | 1.332485 → 0.806437 | 11/20 |
| Rule application / Data's rule-verified labels | 20 / 2 | 5/20 → 7/20 | 1.366589 → 1.362848 | 4/20 |

Overall labels mix 40 teacher and 20 rule-verified rows, not wholly independent correctness. M3 improves this pilot's aggregate score over its own baseline and M2, but rules remain weak and below lexical's 8/20.

Research's published state-free longest-option diagnostic matches 18/20 intent validation labels. M3's 19/20 does not by itself demonstrate robust contextual intent reasoning. This is a measured dataset shortcut, not proof that this model uses that feature. Validation has been used for experiment selection, and two rule mechanisms are not a broad reasoning benchmark. No significance, calibration or final-performance claim.

The new tokenizer audit found zero truncated or question/candidate-loss pairs at 256 across 360 decisions / 1,412 pairs (max 169 tokens). Input loss does not explain the remaining rule weakness.

## Usage and artifacts

```sh
uv run --locked --extra model python -m jeff.training.train \
  --dataset-manifest "$JEFF_ARTIFACTS_DIR/data/data-pilot-v1/manifest.json" \
  --output-dir "$JEFF_ARTIFACTS_DIR/model/YOUR-NEW-M3-RUN" \
  --architecture retained_cross_encoder \
  --model-id cross-encoder/ms-marco-MiniLM-L6-v2 \
  --revision 233902d25c440f23af6f7d6e94d2946bac0bee0a \
  --device mps --max-length 256 --seed 42 --epochs 3 --batch-size 4 \
  --learning-rate 2e-5 --head-learning-rate 5e-4 --threads 4
```
